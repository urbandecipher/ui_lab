      版本紀錄 目前 v6.0 · 2026-10-28
      1. v6.0 · 系統化擴充

        新增 24 個元件（共 90 個）：日期區間、色彩選擇、搜尋框、表單錯誤摘要、選單按鈕、可收合側欄、目錄捲動追蹤、底部分頁列、跳至主內容、兩段式確認、連線狀態、自動儲存、時間軸、統計數字卡、描述清單、圖片燈箱、分割面板、跨欄看板，以及遊戲用的按鍵重新綁定、手把按鍵圖示、存檔欄位、任務追蹤、成就通知、新手教學聚焦。設計變數新增字級、層級、斷點、緩動曲線，既有元件的 z-index 改用層級變數；新增「總則」：文案總則、用詞對照與可勾選的無障礙檢查清單。核心會同步元件內的錨點連結；建置會擋下元件互相借用樣式。

      2. v5.2 · 新元件

        新增 U63 輸入遮罩（手機、身分證檢查碼）、U64 多選下拉（篩選、上限、Backspace 移除）、U65 無限捲動（自動載入、載入更多、失敗重試）、U66 時間選擇器（時／分 spinbutton、時段驗證），共 66 個元件；新增這四個元件的互動測試。

      3. v5.1 · 規範深度

        每個元件新增結構拆解、鍵盤操作表與文案規則（依實際程式行為撰寫），18 個遊戲元件附 Godot 4 節點對應；新增設計變數總表，可複製 var() 並下載 tokens.css／tokens.json；匯出的完整 HTML 開頭附使用規範與鍵盤操作摘要；修正 U24 讀屏標籤。

      4. v5.0 · 原始碼模組化

        每個元件拆成獨立資料夾（規格、標記、樣式、互動），由零相依建置腳本組成單檔；匯出只帶該元件實際用到的 CSS 與 JavaScript；元件內的 ID 依實例自動產生，同一頁可放多個相同元件。

      5. v4.0 · 通用規範集

        新增 18 個通用元件與「資料展示」分類（共 62 個）；每個元件加上「適用／避免」使用規範並可搜尋；示範文案去除專案專屬內容；計數改為自動；匯出沿用正確分類色；移除舊版無作用的覆蓋層。

      6. v3.0 · 設計系統與情境

        全域樣式、偏好保存、樣式匯出、三個完整流程與版本紀錄。

      7. v2.0 · 可取用的元件

        44 個元件的狀態預覽、獨立重設、鍵盤／觸控與程式碼匯出。

      8. v1.1 · 圖鑑導覽

        關鍵字搜尋、分類篩選、獨立連結、全部重設及窄螢幕調整。

      9. v1.0 · 互動圖鑑

        44 個可操作範例、六大分類與深淺色模式。

      UI LAB v6 — 單檔、零相依的互動規範集 · 支援深淺色、鍵盤與觸控 · 每個元件皆可匯出獨立 HTML
